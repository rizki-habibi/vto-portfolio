# VTO Portfolio

**Visi · Teknologi · Organisasi**

Portfolio presentasi VTO — 10 slide interaktif dengan animasi, loading screen, dan navigasi smooth.

## Tech Stack

- React 18 + Vite
- Framer Motion (animasi)
- Tailwind CSS (styling)
- Lucide React (icons)

## Development

```bash
npm install
npm run dev
```

## Deploy ke Vercel

1. Push ke GitHub
2. Import repo di [vercel.com](https://vercel.com)
3. Framework: Vite — auto-detect
4. Deploy!

Atau pakai Vercel CLI:

```bash
npm i -g vercel
vercel
```
